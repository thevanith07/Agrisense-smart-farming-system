# Agrisense-smart-farming-system
portable on-field soil monitoring and smart crop recommendation system.
**Project Overview**
AgriSense is a portable on-field soil monitoring and smart crop recommendation system.
**Problem Statement**
Farmers face difficulties in understanding soil conditions, crop diseases and suitable weather conditions for cultivation.
**Proposed Solution**
**AgriSense helps farmers through:**
- Soil Monitoring
- Crop Disease Detection
- Weather Awareness
- Pesticide Recommendation
- Field Monitoring
**Working Principle**
1. Monitor soil conditions.
2. Detect crop diseases using leaf images.
3. Analyse weather conditions.
4. Recommend suitable pesticides based on soil and weather information.
**Benefits**
- Better crop management
- Reduced unnecessary pesticide usage
- Improved farming decisions
- Easy on-field monitoring
